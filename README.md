# logica-programacion-3

Programa en JavaScript que calcula el factorial de un número.

## Cómo usarlo
1. Abrir `index.html` en el navegador.
2. Hacer clic en "Probar un número" y escribir un entero.
3. El resultado sale en la página y en la consola (F12).

## Pseudocódigo
1. Pedir un número con prompt
2. Convertirlo a number y verificar que sea válido
3. Si es negativo o decimal, mostrar un aviso
4. factorial = 1
5. Para i desde 1 hasta el número: factorial = factorial * i
6. Mostrar el resultado

## Ejemplos
- 4! = 24
- 5! = 120
- 0! = 1
